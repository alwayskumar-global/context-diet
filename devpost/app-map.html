Architecture & Component Map

1. Top-Level State Orchestration
File: src/App.tsx
Holds reactive state for active presets, clause collection, Keep/Trim toggles, and volume slider. Connects heatmap changes directly to the safety badge and token engine.
2. 4-Color Clause Heatmap Viewer
File: src/components/HeatmapViewer.tsx
Renders interactive clause spans with high-contrast strike-through on trimmed filler and reveals pre-computed concise 1-line distillations for Blue verbose prose.
3. Constraint Lock Safety Guard
File: src/components/ConstraintLockBadge.tsx
Calculates hard constraint survival ratio. Emits an immediate high-contrast alert badge (⚠️ Constraint Lock Broken: X% Preserved) if any Green invariant is trimmed, complete with 1-click restore actions.
4. FDA Prompt Nutrition Facts Card
File: src/components/NutritionFactsCard.tsx
Authentic FDA packaging aesthetic with heavy black borders, gross vs diet token metrics, nutrient bloat breakdown, volume slider (1k–200k req/day), and projected monthly USD cost reduction.
5. Client-Side Tokenizer & Compiler
File: src/utils/tokenizer.ts & src/utils/compiler.ts
Fast BPE-approximate tokenizer running 100% in-browser with zero latency or API keys. Compiles surviving clauses and compressed substitutions into clean text.

To Change This, Start Here

  • Add a new prompt preset: Edit src/data/presets.ts and append a new PresetPrompt object with custom categorized clauses.
  • Adjust token pricing rates: Update the modelTier state options in src/components/NutritionFactsCard.tsx.
  • Tune custom heuristic parsing: Modify keyword patterns and regex rules in src/utils/parser.ts.
  • Refine heatmap styling: Adjust color utility classes in src/components/HeatmapViewer.tsx.

A Practice to Reuse

"Pairing Optimization with Invariant Verification": When trimming or refactoring AI prompts, developers hesitate out of fear of behavioral regression. By pairing an aggressive reduction metric (Nutrition Facts) with a strict safety check (Constraint Lock), ContextDiet guarantees that optimization never silently strips critical behavioral rules.

Evidence: src/components/ConstraintLockBadge.tsx strictly guards Green clauses and flips to an immediate warning state upon any violation, creating a deterministic safety net.
